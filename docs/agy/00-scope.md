## 「足够扩展」的三个具体落点

这是本期设计的重点，验收会重点看：

1. **agent 加一种采集项** = 实现 `Collector` 接口 + 注册，**不改主循环、不改协议**
2. **agent 加一种下发动作** = 实现 `Action` 接口 + 注册到动作表，**不改协议**
3. **加一种测速探测方式** = 实现 `Probe` 接口 + 注册，**不改协议、不改服务端调度**

三处都必须是「注册表 + 接口」的形状，不是 `switch case` 堆在主流程里。
