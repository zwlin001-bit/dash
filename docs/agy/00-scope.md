## 「足够扩展」的落点

第一期就要立住的三个扩展点，验收时会要求现场演示：

1. **加一种采集项** = 实现 `Collector` 接口 + 一行 `Register()`，不改主循环、不改协议
2. **加一个页面/图表** = 复用 `TimeSeriesChart`，不另写图表
3. **换数据库** = 只改 `internal/db/dialect` 的三个模板 + 一份 DDL

第二期的「加一种下发动作」「加一种探测方式」沿用同样的注册表形状。
