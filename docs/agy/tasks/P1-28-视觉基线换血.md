## ❷ 新增两个 token（这次唯一允许的扩展）

这套观感的辨识度来自渐变和辉光，现有契约表达不了，补两组：

```css
--accent-gradient: linear-gradient(135deg, var(--accent), var(--accent-hover));
--glow-1: rgba(45, 212, 191, .08);   /* 浅色主题 rgba(13,148,136,.10) */
--glow-2: rgba(56, 189, 248, .07);   /* 浅色主题 rgba(2,132,199,.08)  */
```

**加进 `13-ui-spec.md` §2.4 与 §2.5 的表里**，不许只写在 CSS 不写进规格。

## ❸ 质感落到四处

只改这四处，**不要顺手重做别的组件**：

1. **主按钮**：`.btn.primary` 背景改 `var(--accent-gradient)`，
   加 `box-shadow: 0 4px 14px var(--accent-bg)`，`:active` 时 `translateY(1px)`
2. **登录页**：卡片后面加两团辉光（`filter: blur(110px)` 的圆），
   再叠一层网格背景用 `mask-image: radial-gradient(...)` 向四周淡出。
   ★ 纯装饰元素一律 `pointer-events: none`
3. **输入框聚焦**：`border-color: var(--accent)` + `box-shadow: 0 0 0 3px var(--accent-bg)`
4. **滚动条**：`::-webkit-scrollbar` 宽 10px，thumb 用 `var(--border-light)` +
   `border-radius: var(--radius-full)` + `border: 2px solid transparent; background-clip: content-box`

## ❹ 数字对齐

现有规格要求数字走 `--font-mono`（`cell-mono` 类），保留。
**额外给所有数字加 `font-variant-numeric: tabular-nums`** ——
等宽字体也有比例数字的实现，这一条才是真正保证列对齐的。

★ **不引入 Web Font。** 13-ui-spec.md §2.6 的规定继续有效，
参考实现用的 Inter **不要引**，回退链已经够用。
