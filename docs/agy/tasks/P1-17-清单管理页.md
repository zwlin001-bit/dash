## 目标

**这个任务合并后，第一期的两个目标（监控信息、机器清单维护）在界面上就都齐了。**

## 交付物

**机器清单管理**
- 节点：新建、编辑（名称、备注、排序、隐藏）、删除
- 分组：增删改，节点归组
- 标签：增删改，给节点打/取标签（一个节点多个标签）
- 计费信息：价格、货币、周期、到期时间、自动续费、流量限额与重置日

**装机**
- 生成 enrollment token，直接给出可复制的一键安装命令
- token 列表与作废

**系统设置**
- 域名（先只读展示，在线修改是任务 19 之后的事）
- 数据保留期
- 采集间隔（下发给 agent）
- 修改管理员密码

## 依据

- 接口：[`../../12-api-spec.md`](../../12-api-spec.md) §3–§5、§8
- 界面：[`../../13-ui-spec.md`](../../13-ui-spec.md)

## 约束

- 删除节点要**二次确认**，并提示「时序数据会随保留期自然过期，不会立即删除」
- 一键安装命令要**带上当前域名和刚生成的 token**，用户复制粘贴即可
- 标签编辑要支持一次给多个节点批量打标签——30 台机器逐个点太蠢
- 采集间隔改完要能看到已连接的 agent 生效（不需要重连）

## 验收

1. 节点、分组、标签的增删改在界面上都能完成
2. **批量给多个节点打标签**可用
3. 生成 token → 复制安装命令 → 在一台干净机器上粘贴执行 → 节点出现在列表里并上线
   （这条要等任务 18 完成后再验，PR 里说明）
4. 改采集间隔后，已连接 agent 的上报频率跟着变，且**没有重连**
5. 删除节点后列表刷新正确，关联数据被清理

## 边界

不做域名在线修改（在任务 19 的设计里，第一期只读展示）。
