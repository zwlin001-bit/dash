## 线上现象

- 删除节点/分组**不生效**
- 新增分组**提示「未登录」**
- 其他写操作大概率同样失效

## 根因（已定位，不用再查）

### ❶ 登录态判断是任务 15 留下的 mock

```ts
// web/src/api/auth.ts:53
isAuthenticated: () => {
  return localStorage.getItem('dash_mock_auth') === '1';
}
```

登录态读的是 localStorage 里一个假标记 `dash_mock_auth`，**与服务端真实会话毫无关系**。
这是搭脚手架时接 mock 数据留下的，一直没换成真的。

任务 22 加鉴权**之前**不暴露（后端本来就不鉴权）；22 之后穿帮：

```
localStorage 有标记 → ProtectedRoute 放行 → 页面渲染
     ↓
请求实际带的 cookie 已过期/不存在 → 后端 401
     ↓
读请求：TanStack Query 静默失败 → 页面显示旧数据或空
写请求：错误冒泡 → 提示「未登录」     ← 用户看到的
```

★ **「删除不生效」和「新增分组提示未登录」是同一个病。**

### ❷ 401 之后没有任何处理

```ts
// web/src/api/client.ts:51
window.dispatchEvent(new CustomEvent('dash:unauthorized'));
```

这个事件**全项目没有监听者**。用户既不会被送去登录页，也不会被提示重新登录。

## 目标

**登录态以服务端会话为准，401 一律把用户送回登录页。**

## 交付物

```
web/src/api/auth.ts        删除 dash_mock_auth，改为真实会话
web/src/App.tsx            ProtectedRoute 改用真实登录态
web/src/api/client.ts      401 的统一处理接上
```

## 约束

### 登录态的真相来源是服务端

- ★ **删掉 `dash_mock_auth` 及一切 localStorage 登录标记**，
  全仓库 grep `dash_mock_auth` 必须为 0
- 会话 cookie 是 `HttpOnly`，**前端读不到也不该读**。
  判断登录态的唯一方式是**调 `GET /api/v1/me`**：200 = 已登录，401 = 未登录
- 应用启动时先调一次 `/api/v1/me` 确定登录态，期间显示加载态，
  **不要先渲染页面再发现没登录**
- 用 TanStack Query 缓存 `/api/v1/me` 的结果（`staleTime` 给几分钟），
  避免每次路由切换都打一次

### 401 统一处理

- `client.ts` 收到 401 时：清掉本地用户缓存 → **跳转 `/login`**，
  并带上 `?from=<当前路径>`，登录后跳回
- ★ **`/api/v1/login` 自身的 401 不能触发跳转**（否则密码输错会陷入循环），
  要把登录端点排除掉
- 跳转要防抖：并发多个请求同时 401 时只跳一次

### 登录页

- 登录成功后跳回 `from`，没有则去 `/nodes`
- 密码错误显示后端返回的 message，**不要显示成「未登录」**
- 被限流（429）时显示「尝试过多，请 15 分钟后再试」

## 验收

★ **必须在浏览器里实跑，不能只看代码。**

1. **未登录访问 `/machines`** → 自动跳 `/login`，**不是白屏也不是空列表**
2. **登录后** → 跳回 `/machines`，列表正常
3. ★ **新增分组** → 成功，列表立即出现新分组（这是本次故障的直接复现项）
4. ★ **删除节点/分组/标签** → 真的删掉，刷新后不再出现
5. **会话失效模拟**：登录后在浏览器里删掉 `dash_session` cookie（或等过期），
   再点任意操作 → **自动跳登录页**，不是卡住或提示「未登录」后无反应
6. **登录时输错密码** → 显示「用户名或密码错误」，**停在登录页不跳转、不循环**
7. 连错 6 次 → 显示限流提示
8. 全仓库 `grep -r "dash_mock_auth" web/` → **0 命中**

## 边界

不改后端。22 的鉴权是对的，问题全在前端。
