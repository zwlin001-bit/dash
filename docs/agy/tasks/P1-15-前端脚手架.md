# P1-15 前端脚手架与图表组件

> 第一期 · 任务 15/19 ｜ 前置：01 ｜ 分支：`agy/p1-15-web-scaffold`

## 目标

前端工程 + 一个监控和后续测速都要复用的时序图表组件。
**不依赖任何后端接口**，接 mock 数据即可。

## 交付物

```
web/
  构建工具链（TypeScript）
  路由骨架：登录 / 节点总览 / 节点详情 / 机器清单 / 系统设置
  api/         统一的请求封装（鉴权、错误处理、SSE）
  components/
    TimeSeriesChart   ★ 时序图表组件
  mock/        假数据
internal/api/web.go   go:embed 内嵌前端产物
```

★ **开工前先读 [`../../08-field-map.md`](../../08-field-map.md)**，字段名、单位、聚合方式全部以它为准。

## 约束

- **前端产物内嵌进 dashd 二进制**（`go:embed`），部署时不需要单独的 web 服务器。
  这是「一条命令部署」的前提
- ★ **时序图表组件监控和测速共用一套**，第二期的测速趋势图会直接复用它。
  入参形状按任务 13 的查询返回定义，**两边定好一次，之后不要各改各的**
- 组件要支持四个跨度（6h / 3d / 60d / 1y）和多指标叠加
- 实时数据走 SSE，**不轮询**
- 不追求好看，追求够用和能复用

## 验收

1. `make build` 后，`bin/dashd` **单文件启动就能打开登录页**（不需要任何外部文件）
2. 图表组件用 mock 数据能渲染四个跨度
3. 图表组件的入参类型定义与任务 13 的接口返回一致（贴出两边的类型对照）
4. 页面路由都能打开（内容可以是空壳）

## 边界

**只做脚手架和组件，接 mock 数据。不接真实接口**（任务 16、17 做）。
