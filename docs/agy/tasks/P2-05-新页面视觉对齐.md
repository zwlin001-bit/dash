## 问题

P1-28 把全站换成暗色优先的新配色，验收时 `.module.css` 里字面量颜色是 **0 命中**。

但 P2-01~04 是**并行开发**的，四个新页面各自写了一套硬编码颜色。合并后一查：

| 文件 | 字面量颜色 |
|---|---|
| `web/src/pages/Jobs/Jobs.module.css` | 35 处 |
| `web/src/pages/Settings/Settings.module.css` | 21 处 |
| `web/src/pages/Cloud/Cloud.module.css` | 10 处 |
| `web/src/pages/CloudGuard/CloudGuard.module.css` | 1 处 |

这违反的不是 P1-28，是 **`13-ui-spec.md` §2 一直就写着的规定**：

> **所有颜色、间距、圆角一律走变量，组件里不许出现字面量颜色值。**

★ **后果是这四个页面在浅色主题下会穿帮**：
`rgba(0, 0, 0, 0.5)` 的遮罩、`#94a3b8` 的次要文字，都是照着暗色底调的，
换到白底上要么看不见要么刺眼。

## ❶ 替换成 token

有些能直接对上，照着换：

| 字面量 | 换成 |
|---|---|
| `#34d399` | `var(--ok)` |
| `#f87171` | `var(--err)` |
| `#38bdf8` | `var(--accent-hover)` |
| `#2dd4bf` | `var(--accent)` |
| `#fbbf24` / `#f59e0b` | `var(--warn)` |

对不上的（各种蓝、橙、灰，以及 `rgba(0,0,0,.5)` 这类遮罩）**逐个判断它想表达什么**：

- 状态色 → 落到 `--ok` / `--warn` / `--err` / `--accent`
- 次要文字 → `--text-dim` / `--text-mute`
- 面板、分隔、悬停 → `--bg-card-sub` / `--border-main` / `--bg-hover`
- 图表系列色 → `--color-teal/cyan/blue/yellow/red/purple`（**只给图表用**）
- 模态遮罩 → ★ **需要新 token**，见 ❷

★ **不要为了消掉 grep 就硬套一个语义不对的 token。**
状态色和图表色是两套东西，混用会让「离线」和「第三条曲线」变成同一个颜色。

## ❷ 补一个遮罩 token

`rgba(0,0,0,0.5)` / `rgba(0,0,0,0.65)` 出现了 5 次，现有契约里没有对应变量。补一个：

```css
--overlay: rgba(2, 6, 14, .62);    /* 暗色 */
--overlay: rgba(15, 30, 60, .45);  /* 浅色 */
```

★ **两个主题下都要定义**，并写进 `13-ui-spec.md` §2.5。

## ❸ 加守卫，别再靠人记

P1-25 的教训摆在那儿：**靠人记住不可靠，要让工具挡住。**

交付 `scripts/lint-css-tokens.sh`，扫 `web/src/**/*.module.css` 与
`.tsx` 里的内联 `style={{...}}`，命中字面量颜色就失败：

- 匹配 `#rgb` / `#rrggbb` / `#rrggbbaa` / `rgb(` / `rgba(` / `hsl(`
- ★ **只放行 `web/src/styles/tokens.css`** —— 它是唯一该出现字面量的地方
- ★ **不许用行内注释豁免**（`/* lint-ignore */` 这类）。开了这个口子就等于没有守卫
- 挂进 `make lint`，**并且挂进 `make build`** —— 理由同 P1-25：很多人只跑 build

误报处理：`transparent`、`currentColor`、`inherit`、`none` 不算字面量颜色。
