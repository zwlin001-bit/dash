## 约束 —— Oracle 侧逐条对照

| 不许写 | 要写 | 原因 |
|---|---|---|
| `BIGINT` | `NUMBER(19)` | **Oracle 没有 BIGINT** |
| `BOOLEAN` | `NUMBER(1)` 存 0/1 | Oracle 无 BOOLEAN |
| `TIMESTAMP` / `DATE` 列 | `NUMBER(19)` 存 epoch 毫秒 | 绕开时区与日期类型差异 |
| `DOUBLE PRECISION` | `BINARY_DOUBLE` | 前者在 Oracle 退化成软件浮点，聚合慢一个数量级 |
| `CHAR(26)` | `VARCHAR2(26)` | CHAR 有空格补齐比较语义，会坑人 |
| `VARCHAR2(n)` | `VARCHAR2(n CHAR)` | **字符语义**，否则中文按字节算会截断 |

其余：
- 主键一律**应用生成的 ULID**，无 IDENTITY / SEQUENCE / AUTO_INCREMENT
- 标识符全小写、**不加引号**、≤30 字符、避开 `02-database.md` §1.3 的保留字黑名单
  （`user` `group` `size` `comment` `level` `mode` `start` `end` `session` `resource` 等）
- 可选字符串列一律可空，**不依赖 `''` 与 NULL 的区别**（Oracle 里两者等价）
- 无触发器 / 存储过程 / 序列 / 物化视图 / 分区表
- 时序表用复合主键 `(node_id, ts_ms)` / `(series_id, ts_ms)`，**不额外建索引**——主键就是查询模式
- 两份 DDL 的**表名列名必须完全对应**

## 验收

1. 空库上 `make migrate` 建出全部表，退出码 0
2. **重复执行幂等**，不报错
3. **对比测试**：分别在 ADB 和本地 docker MySQL 8 跑完迁移，
   对比 `information_schema` 的表名列名集合，不一致即失败。**这个测试必须交付**
4. `scripts/lint-sql.sh` 通过（迁移文件本身不在扫描范围，但 Go 代码要过）
5. PR 里贴出 ADB 上 `select table_name from user_tables order by 1` 的实际输出

## 边界
