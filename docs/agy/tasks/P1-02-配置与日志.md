# P1-02 配置与日志

> 第一期 · 任务 02/19 ｜ 前置：01 ｜ 分支：`agy/p1-02-config-log`

## 目标

统一的配置读取和日志输出。**所有机密都要能被自动打码。**

## 交付物

```
internal/config/    读 /etc/dash/config.toml，支持 DASH_* 环境变量覆盖
internal/logx/      结构化日志 + redact 打码函数
deploy/config.example.toml   已存在，按实现校准
```

配置项参考 `deploy/config.example.toml`：`[db]` 段（driver/user/password/dsn/wallet_path/连接池）、
`[server]` 段（listen/listen_acme/data_dir）。

## 接口签名（照这个写）

```go
package config

type Config struct {
    DB     DBConfig     `toml:"db"`
    Server ServerConfig `toml:"server"`
}

type DBConfig struct {
    Driver          string `toml:"driver"`            // "oracle" | "mysql"
    User            string `toml:"user"`
    Password        string `toml:"password"`          // 支持 ${DASH_DB_PASSWORD} 占位
    DSN             string `toml:"dsn"`
    WalletPath      string `toml:"wallet_path"`
    MaxOpenConns    int    `toml:"max_open_conns"`    // 默认 20
    MaxIdleConns    int    `toml:"max_idle_conns"`    // 默认 10
    ConnMaxLifetimeS int   `toml:"conn_max_lifetime_s"` // 默认 1800
}

type ServerConfig struct {
    Listen     string `toml:"listen"`      // 默认 ":443"
    ListenACME string `toml:"listen_acme"` // 默认 ":80"
    DataDir    string `toml:"data_dir"`    // 默认 "/var/lib/dash"
    MasterKey  string `toml:"master_key"`  // 默认 "/etc/dash/master.key"
}

func Load(path string) (*Config, error)   // 文件 → 环境变量覆盖 → 校验 → 填默认值
func (c *Config) Validate() error
func (c *Config) Redacted() *Config       // 深拷贝并把机密替换成 "***"，用于日志
```

```go
package logx

func Init(level string, format string)    // format: "json" | "text"
func Debug(msg string, kv ...any)
func Info(msg string, kv ...any)
func Warn(msg string, kv ...any)
func Error(msg string, kv ...any)
func With(kv ...any) *Logger              // 带上下文的子 logger

// Redact 是全工程唯一允许输出可能含机密内容的途径
func Redact(s string) string
func RedactDSN(dsn string) string         // 专门处理 DSN 里内嵌的密码段
```

底层用标准库 `log/slog`，**不引入第三方日志库**（P3 依赖纪律）。

### 必须打码的内容

| 来源 | 规则 |
|---|---|
| `DBConfig.Password` | 整体 `***` |
| `DSN` | 匹配 `password=…` / `//user:pw@` 形式，只替换密码段，保留其余便于排查 |
| wallet 密码 | 整体 `***` |
| agent token / session token / enrollment token | 只保留后 4 位：`***abcd` |
| 主密钥内容 | 永远不输出，连打码后的都不输出 |

**环境变量覆盖规则**：`DASH_` + 大写路径，`.` 换成 `_`。
例：`DASH_DB_PASSWORD`、`DASH_SERVER_LISTEN`。

### 配置项与设置项的边界

★ **能放数据库的都放数据库。** `config.toml` 只放「不连数据库就没法启动」的东西。
域名、保留期、采集间隔全在 `settings` 表（`10-schema-spec.md` §1、§5），
**不要往 `config.toml` 里加它们**。

## 约束

- **域名不在配置文件里**，在数据库 `settings` 表的 `site.domain`（P5.4）。
  配置文件只放「不连数据库就没法启动」的自举项
- 优先级：命令行 > 环境变量 > 配置文件
- 日志写 **stderr**，结构化（JSON 或 key=value），**不自己做文件轮转**——交给 systemd/OpenRC
- **`logx` 必须提供 redact 函数，并且是唯一允许输出配置内容的途径。**
  密码、token、wallet 密码、DSN 里的密码段，一律打码成 `***`
- 数据库密码支持从环境变量 `DASH_DB_PASSWORD` 读，避免落在文件里

## 验收

1. 配置文件 + 环境变量 + 命令行三种来源的优先级正确（写单元测试覆盖）
2. **把一个带密码的完整配置打进日志，输出里翻不到明文密码**——这条会实际去 grep 日志
3. DSN 里内嵌密码的情况也要被打码
4. 配置文件缺失时给出可读的错误信息，不是 panic

## 边界

不做主密钥/信封加密（第一期不存云厂商凭据）。不做 ACME、不做数据库连接。
