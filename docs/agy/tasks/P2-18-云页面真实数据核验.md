## 背景

用户问「云账单和流量守卫是不是还是 mock 假数据」。

★ **核对结果：前端没有 mock。** Billing / CloudGuard / Cloud / Alerts / Jobs
五个页面全部走 `useQuery` 打真实 API，`web/src` 下已无任何写死的假数据
（P1-26 删掉了 `web/src/mock/`，P2-05 之后连硬编码颜色都没了）。

**但用户看到假数据这件事是真的**，原因在别处：
生产 dashd 连的是测试库（见 **P2-17**），测试跑一次就往里写一次假数据 ——
装机命令里那个 `custom.domain.org` 就是 `download_test.go` 写进去的。

所以 **P2-17 必须先做完**。本任务是在库修对之后，做一次端到端核验。

## 目标

**用真实阿里云账号跑一遍，逐项核对界面数字与阿里云控制台一致。**

这不是写代码的任务，是**验证任务**。发现不一致就记录下来交回验收，
★ **不要自己顺手改业务代码** —— 由我判断是显示问题还是采集问题。
