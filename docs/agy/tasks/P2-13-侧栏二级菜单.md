# P2-13 侧栏改二级菜单

> 第二期 · 任务 13 ｜ 前置：无 ｜ 分支：`agy/p2-13-nav-tree` ｜ **预计半天**

> ★ **完成后必须自己 `git push -u origin <分支名>`**。

## 目标

侧栏现在是 9 个平铺条目，已经太长。改成两级。

## 新的信息架构

```
监控
├─ 节点总览        /nodes
├─ 机器清单        /machines
├─ 事件            /events
└─ 告警            /alerts

阿里云
├─ 云资产          /cloud
├─ 流量守卫        /guard
└─ 云账单          /billing

系统设置
├─ 任务中心        /jobs
└─ 设置            /settings
```

★ **路由路径一个都不改。** 只改侧栏的分组呈现 ——
改路径会让所有已有链接、书签、`?from=` 回跳全部失效，收益为零。

## 约束

- 一级项**可折叠**，折叠状态存 `localStorage`（`13-ui-spec.md` §3 已有主题存储的先例）
- ★ **当前路由所在的一级项默认展开**，刷新后不能收起来让人找不到自己在哪
- 一级项本身**不是链接**，点击只做展开/收起
- 二级项高亮沿用现有 `navLinkActive`
- 一级项上带该组的**未读/异常计数徽章**（事件未读数、firing 告警数、失败 job 数），
  折叠时也能看到那一组里有事
- 颜色走 token，`lint-css-tokens` 会拦
- 窄屏（≤768px）行为与现在一致，不要顺手重做移动端

## 验收

1. 九个页面都能从新侧栏进到，路径未变
2. 折叠某一组 → 刷新后仍折叠；★ 但**当前所在组始终展开**
3. 有未读事件 / firing 告警 / 失败 job 时，对应一级项显示徽章，折叠时也可见
4. 深色 / 浅色 / 跟随系统三种主题下都不穿帮
5. `make lint`、`npm run build`、`npm test` 全绿
6. `docs/13-ui-spec.md` §4 布局一节更新为二级结构

## 边界

- 不改路由路径
- 不改页面内容
- 不做面包屑
