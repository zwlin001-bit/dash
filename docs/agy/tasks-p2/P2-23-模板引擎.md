# P2-23 模板引擎

> 第二期 · 任务 23 ｜ 前置：20 ｜ 分支：`agy/p2-23-template` ｜ 迁移编号：无
> 设计依据：[`../../09-events-notify.md`](../../09-events-notify.md) §5

## 目标

**模板是文件，不是代码。改模板不用改代码、不用发版。**

## 交付物

```
internal/template/
  loader.go     加载 + 热重载
  render.go     渲染 + 函数白名单
  funcs.go      fmtTime / fmtDur / fmtBytes / fmtPct / default
  builtin/      内置默认模板（go:embed）
  README.md
/etc/dash/templates/{telegram,webhook}/*.tmpl   安装时释放
```

## 约束

- 查找顺序：`notify_rules.template_name` → `<event_type>.tmpl` → `_default.tmpl`
- ★ **内置默认模板随二进制发布**（`go:embed`），安装时释放到 `/etc/dash/templates/`。
  用户改了用用户的，删了回落内置——**保证一键部署不需要用户先写模板**
- Go `text/template`，★ **函数白名单，不允许任意函数调用**。
  就 §5.1 那五个，要加得改代码
- **热重载**：文件改动后自动生效，不重启进程。用 mtime 轮询即可，不必上 inotify
- ★ **渲染失败不允许吞掉通知**：回落 `_default.tmpl`，
  并产生一条 `system.template_error` 事件。**通知系统自己坏掉必须被通知到**
- 通用变量所有模板都有：`.EventType` `.Severity` `.Title` `.OccurredAtMs`
  `.TargetKind` `.TargetId` `.SiteDomain`；类型特有变量来自 `events.payload_json`
- 提供 `Preview(eventType, templateText)` 供界面预览用

## 验收

1. 改一个 `.tmpl` 文件，**不重启进程**，下一次渲染就用新内容
2. 删掉某个 `.tmpl`，渲染回落到内置默认模板，不报错
3. 模板里写一个不存在的变量 → 回落 `_default.tmpl` + 产生 `system.template_error` 事件
4. 模板里尝试调用白名单外的函数 → 加载时就报错，不是运行时才炸
5. 五个格式化函数各有单元测试（含边界：0 字节、负数、超大值）
6. 全新安装后 `/etc/dash/templates/` 里有可用的默认模板

## 边界

只做渲染，不做发送、不查数据库拿路由。输入是「事件 + 模板名」，输出是文本。
